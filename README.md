# Yousef Osama Anwar — Portfolio

Professional portfolio for an automotive mechatronics specialist in Egypt. The page presents automotive diagnostics experience, technical skills, training, WorldSkills recognition and an electromechanical train-step project.

The site is a static HTML, CSS and JavaScript page. Profile photographs and the hero background (`assets/Back.jpg`) are stored in `assets/`, the tab icon is `favicon.svg`, and the train-step project image is in `assets/projects/`.

## GitHub

Repository: https://github.com/gitbhub998-collab/yousef-osama-4

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no build step or dependencies are required.
